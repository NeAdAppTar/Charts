A program for plotting graphs based on telemetry data. It is possible to customize your own data order. 
Processes ID;t;h;p;T;aX;aY;aZ;gX;gY;gZ;f1;f2;f3;f4. 
Builds 5 graphs: Graph of height from time, Graph of pressure from time, Graph of height from temperature, Graph of acceleration (along three axes and vector acceleration), Graph of angular velocity (along three axes). 
For All-Russian Championship "VISh". // SR 2025
